# Eon: The Forge Awakens — Game Design

Design documents for the game built on top of Eon Engine.

- [game_mechanics.md](game_mechanics.md) — Core defense and XP curves, progression philosophy, leveling constants, and the mathematical backbone of player growth.
- [game_calculations.md](game_calculations.md) — Unified combat math: damage formula, mitigation, threat level scaling, and crit calculations.
- [game_map.md](game_map.md) — The Map Forge system: materials, map blueprints, templates, affix modifiers, and endgame map scaling. The primary late-game content loop.
- [game_pinnacle_bosses.md](game_pinnacle_bosses.md) — Pinnacle encounter design: boss tiers, scaling, unique rewards, and the re-forging system for replaying encounters.
- [game_skills_crafting.md](game_skills_crafting.md) — Skills, the crafting loop, affix slots, material tiers, and item progression philosophy.
- [game_player_experience.md](game_player_experience.md) — Core player experience principles: traversal feel, information design, early game onboarding, and the power fantasy philosophy.
- [game_items_misc.md](game_items_misc.md) — Satirical RNG drop humor and world-flavor items that reinforce the game's anti-RNG, craft-over-chance ethos.
